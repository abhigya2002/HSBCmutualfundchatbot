# Phase 0 — Foundation and scope freeze

**Goal:** Lock problem boundaries, schemes, compliance acceptance criteria, and corpus rules before implementation.

**Architecture reference:** `phase-wise-architecture.md` (Phase 0 and §1–2.1).

## Deliverables (this folder)

| Document | Purpose |
|----------|---------|
| [scope.md](scope.md) | AMC, scheme list, strict Groww allowlist, constraints, UI expectations |
| [query-policy-matrix.md](query-policy-matrix.md) | Allowed vs refused intents, handling rules, default citation for refusals |
| [acceptance-checklist.md](acceptance-checklist.md) | Per-response QA checklist |
| [risk-register.md](risk-register.md) | Initial risks and mitigations |
| [stakeholder-signoff.md](stakeholder-signoff.md) | Exit criteria checklist and sign-off template |

## Exit criteria

- Stakeholder-approved **scope** (`scope.md`).
- Stakeholder-approved **query policy matrix** (`query-policy-matrix.md`).
- Risk register reviewed (no blocking items unowned).
